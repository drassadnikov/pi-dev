Obsidian CLI: команды `obsidian` выполнять ТОЛЬКО ПО ОДНОЙ ЗА РАЗ (последовательно), никогда несколькими параллельными вызовами в одном блоке — каждый eval перебирает все md-файлы волюта, а 2+ параллельных eval блокируют приложение и дают ошибку «obsidian eval timed out (killed via SIGKILL) after 30000ms». Для search/replace по всему вольту всегда передавать timeout_ms=60000. После timeout-ошибки перед повтором проверить, что замена уже применилась (eval мог завершиться до SIGKILL), чтобы не задвоить правку.
